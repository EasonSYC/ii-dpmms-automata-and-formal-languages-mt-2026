\section{Regular Languages and Finite-State Automota}
\subsection{Deterministic Finite-State Automata (DFA)}

Suppose we want to describe a language \(L\) over \(\Sigma\), using only a finite amount of information. We could extend \(\Sigma\) with other symbols to an alphabet \(\Pi\) and assign (non-uniquely) a particular a word \(w \in \Pi\kstar\) to \(L\). But we can only do this for countably many \(L\). But we want \(w\) to \term{describe} \(L\).

\begin{example}
    For example, if \(\Sigma = \Bqty{0, 1}\) and \(L\) is all words over \(\Sigma\) that start with a \(1\). We can use \(\Pi = \Bqty{0, 1, a, \ldots, z, \_}\) and using natural language, \(w = \texttt{all words over \(\Sigma\) that start with a \(1\)}\).
\end{example}

We will see a countable class of languages, where we can do this not via natural language, but symbolically We first give a computational method to determine these languages.

\begin{definition}[Deterministic Finite-State Automaton (DFA)]
    A \term{deterministic finite-state automaton (DFA)} is a quintuple \(D = \pqty{Q, \Sigma, \delta, q_0, F}\) consisting of:
    \begin{itemize}
        \item a finite non-empty set of \term{states} \(Q\),
        \item an alphabet \(\Sigma\),
        \item a \term{transition function} \(\functiondomain{\delta}{Q \times \Sigma}{Q}\),
        \item a \term{starting state} \(q_0 \in Q\),
        \item a set of \term{accept states} \(F \subseteq Q\).
    \end{itemize}
\end{definition}

\begin{remark}
    The input to a DFA is any word \(w \in \Sigma\kstar\). The DFA starts in the starting state \(q_0\), and reads the first letter \(x_1\). It then moves to \(\delta\pqty{q_0, x_1}\) and reads \(x_2\), hence moving to \(\delta\pqty{\delta\pqty{q_0, x_1}, x_2}\), etc.

    When all letters of \(w\) is read, if the DFA is in an accept state, then \(w\) is \term{accepted}, and otherwise \(w\) is \term{rejected}.
\end{remark}

\begin{example*}
    The empty string \(\emptyword\) is accepted, if and only if \(q_0 \in F\).
\end{example*}

\begin{definition}[Transition Diagram]
    A \term{transition diagram} of a DFA \(D\) is a directed, labelled graph such that
    \begin{enumerate}[label=(\arabic*)]
        \item the vertex set is \(Q\),
        \item for each \(\pqty{q, \sigma} \in Q \times \Sigma\), draw an directed edge from \(q\) to \(\delta\pqty{q, \sigma}\) labelled by \(\sigma\). (This means there are exactly \(\abs{\Sigma}\) out-edges from every vertex.)
        \item add an arrow from ``nowhere'' to \(q_0\) to indicate the starting state,
        \item draw double circles around the accept states in \(F\) (and single circles otherwise).
    \end{enumerate}

    If there are lots of edges from some vertex to the same vertex, then we can draw one edge with label which is a subset of \(\Sigma\).
\end{definition}

\end{example*}

\begin{definition}[Transition Table]
    A \term{transition table} of a DFA \(D\) is a table with rows indexed by the states \(Q\) and columns indexed by the alphabet \(\Sigma\), such that the entry in row \(q\) and column \(\sigma\) is \(\delta\pqty{q, \sigma}\).
\end{definition}

\subsection{Regular Languages}

\begin{definition}[Extended Transition Function (DFA)]
    \label{def:extended-transition-function-dfa}%
    The \term{extended transition function} of a DFA \(D\) is given by
    \[
        \functiondomain{\hat{\delta}}{Q \times \Sigma\kstar}{Q}
    \]
    defined inductively by
    \begin{itemize}
        \item \(\hat{\delta} \pqty{q, \epsilon} = q\),
        \item \(\hat{\delta} \pqty{q, \sigma_1} = \delta(q, \sigma_1)\), and
        \item \(\hat{\delta} \pqty{q, \sigma_1 \ldots \sigma_k} = \delta \pqty{\hat{\delta} \pqty{q, \sigma_1 \ldots \sigma_{k - 1}}, \sigma_k}\).
    \end{itemize}
\end{definition}

For any \(w \in \Sigma\kstar\), we have \(\hat{\delta}\pqty{q_0, w}\) is the end state of an input \(w\).

\begin{lemma}[Transitivity of Extended Transition Function]
    For all \(1 \leq l \leq k\), we have
    \[
        \hat{\delta}\pqty{q, \sigma_1 \ldots \sigma_k} = \hat{\delta}\pqty{\hat{\delta}\pqty{q, \sigma_1 \ldots \sigma_l}, \sigma_{l + 1} \ldots \sigma_k}.
    \]
\end{lemma}

\begin{proof}
    We may show by induction on \(k\). Base case \(k = 1\) is trivial. Suppose the result holds for \(k - 1\). Then
    \begin{align*}
        \hat{\delta}\pqty{q, \sigma_1 \ldots \sigma_k} &= \delta\pqty{\hat{\delta}\pqty{q, \sigma_1 \ldots \sigma_{k - 1}}, \sigma_k} \\
        &= \delta\pqty{\hat{\delta}\pqty{\hat{\delta}\pqty{q, \sigma_1 \ldots \sigma_l}, \sigma_{l + 1} \ldots \sigma_{k - 1}}, \sigma_k} \\
        &= \hat{\delta}\pqty{\hat{\delta}\pqty{q, \sigma_1 \ldots \sigma_l}, \sigma_{l + 1} \ldots \sigma_k}.
    \end{align*}
\end{proof}

\begin{definition}[Regular Languages]
    Let \(D\) be a DFA. The \term{language accepted by \(D\)}, denoted by \(\langacc{L}(D)\), is the set of all words accepted by \(D\), i.e., the set of all \(w \in \Sigma\kstar\) such that \(\hat{\delta}\pqty{q_0, w} \in F\).
    
    A language \(L \subseteq \Sigma\kstar\) is \term{regular} if there exists a DFA \(D\) such that \(L = \langacc(D)\).
\end{definition}

\subsection{Non-Determinism and \(\emptyword\)-Transitions}

We now examine a (seemingly) more general construction, where we can choose which state to move to (or equivalently, moving to many states simultaneously).

\begin{definition}[Non-Deterministic Finite-State Automaton (NFA)]
    A \term{non-deterministic finite-state automaton (NFA)} is a quintuple \(N = \pqty{Q, \Sigma, \delta, q_0, F}\) consisting of:
    \begin{itemize}
        \item a finite non-empty set of \term{states} \(Q\),
        \item an alphabet \(\Sigma\),
        \item a \term{transition function} \(\functiondomain{\delta}{Q \times \Sigma}{\powerset\pqty{Q}}\),
        \item a \term{starting state} \(q_0 \in Q\),
        \item a set of \term{accept states} \(F \subseteq Q\).
    \end{itemize}
\end{definition}

\begin{remark}
    Note the difference of a NFA from a DFA is that the transition function \(\delta\) now maps to a \emph{set of states}, rather than a single state. This means that, for a given state and input symbol, the NFA can transition to a number of possible next states, possibly none at all (discussed below).
\end{remark}

An NFA has input \(w = \sigma_1, \ldots, \sigma_k \in \Sigma\kstar\) while in state \(q_0\), reads \(\sigma\), then ``moves to'' all states in \(\delta\pqty{q_0, \sigma_1} \subseteq Q\). For each of these states, it reads \(\sigma_2\) and moves to all states in \(\delta\pqty{q, \sigma_2}\), so we are now at
\[
    \bigcup_{p \in \delta\pqty{q_0, \sigma_1}} \delta\pqty{p, \sigma_2} \subseteq Q,
\]
etc. We continue to get ``end states'' \(E_W \subseteq Q\). If any of the resulting states after reading the entire input \(w\) is an accept state, i.e., \(E_w \cap F \neq \emptyset\), then \(w\) is accepted by the NFA, and otherwise \(w\) is rejected.

It could be well possible that \(\delta\pqty{p, \sigma} = \emptyset\) as \(\emptyset \in \powerset\pqty{Q}\). But what if we are currently in the set of states \(S \subseteq Q\), and we read \(\sigma\), only to find
\[
    \bigcup_{p \in S} \delta\pqty{p, \sigma} = \emptyset?
\]

Then we are in ``no state'' (the set of states is empty), and the NFA rejects the input \(w\).

Given an NFA \(N\), we may define the transition diagram and table in the same way as for a DFA.

    Consider \autoref{fig:nfa-example}. If we read the word \(w = \sigma_1 \sigma_2\), then after state one, we are in the set of states \(\Bqty{a, b, d}\). After reading \(\sigma_2\), we are in the set of states \(\Bqty{c, q_0, d}\).
\end{example*}

\begin{definition}[Extended Transtion Function (NFA)]
    \label{def:extended-transition-function-nfa}%
    The \term{extended transition function} of an NFA \(N\) is given by
    \[
        \functiondomain{\hat{\delta}}{Q \times \Sigma\kstar}{\powerset\pqty{Q}}
    \]
    defined inductively by
    \begin{itemize}
        \item \(\hat{\delta} \pqty{q, \epsilon} = \Bqty{q}\),
        \item \(\hat{\delta} \pqty{q, \sigma_1} = \delta(q, \sigma_1)\), and
        \item the inductive step
        \[
        \hat{\delta} \pqty{q, \sigma_1 \ldots \sigma_k} = \bigcup_{p \in \hat{\delta}\pqty{q, \sigma_1 \ldots \sigma_{k - 1}}} \delta\pqty{p, \sigma_k}.
        \]
    \end{itemize}
\end{definition}

In other words, \(\hat{\delta}\pqty{q, w}\) is the set of all ``end states'' \(E_w\)after reading \(w\) starting from \(q\).

Furthermore, it is going to be even more flexible, if we can change \emph{certain} states, without reading a symbol. Such transitions are called \term{\(\emptyword\)-transitions}. We would like to think of this as reading \(\emptyword\) (``nothing'') between the letters, whenever and as often as we like.

\begin{definition}[\(\emptyword\)-NFA]
    An \term{\(\emptyword\)-NFA} is a quintuple \(E = \pqty{Q, \Sigma, \delta, q_0, F}\) just like an NFA, except that the \term{transition function} is now
    \[
        \functiondomain{\delta}{Q \times \pqty{\Sigma \cup \Bqty{\emptyword}}}{\powerset\pqty{Q}}.
    \]
\end{definition}

Here, rather than the empty word being a symbol, it ``acts as a symbol''.

Now, we want to define how we process a word.

\begin{definition}[\(\emptyword\)-Closure]
    For an \(\emptyword\)-NFA \(E\) and a state \(Q\), we define the \term{\(\emptyword\)-closure} \(\ecl\pqty{q}\) of \(q\) as the set of states reached from \(q\), by repeated \(\emptyword\)-transitions. That is, define inductively \(S_0 \pqty{q} = \Bqty{q}\), \(S_1 \pqty{q} = \Bqty{q} \cup \delta\pqty{q, \emptyword}\), and 
    \[
        S_{i + 1} \pqty{q} = S_i \pqty{q} \cup \bigcup_{r \in S_i\pqty{q}} \delta\pqty{r, \emptyword}.
    \]
    and
    \[
        \ecl\pqty{q} = \bigcup_{i = 0}^{\infty} S_i\pqty{q} = S_N\pqty{q} \subseteq Q.
    \]
    for some \(N\) (since this is an ascending chain of finite sets, which are subsets of a finite set).

    The \term{\(\emptyword\)-closure} of a set of states \(S \subseteq Q\) is defined as
    \[
        \ecl\pqty{S} = \bigcup_{q \in S} \ecl\pqty{q}.
    \]

    Clearly we have \(S \subseteq \ecl\pqty{S}\), and the \(\emptyword\)-closure of a union of sets is the union of the \(\emptyword\)-closures of the sets.

    A given set of state \(R \subseteq Q\) is \term{\(\emptyword\)-closed} if \(\ecl\pqty{R} = R\).
\end{definition}

\begin{lemma}[\(\emptyword\)-Closure is \(\emptyword\)-Closed]
    For any \(S \subseteq Q\), \(\ecl\pqty{S}\) is \(\emptyword\)-closed.
\end{lemma}

\begin{proof}
    Let \(C = \ecl\pqty{S}\). We would like to show that
    \[
        \ecl\pqty{C} \subseteq C = \ecl\pqty{S}.
    \]

    Let \(x \in \ecl\pqty{C}\). Then \(x \in \ecl\pqty{r}\) for some \(r \in C\). So there exists some finite sequence of \(\emptyword\)-transitions from \(r\) to \(x\), i.e. mathematically, we have \(r_0 = r\), \(r_1 \in \delta\pqty{r_0, \emptyword}\), \(r_2 \in \delta\pqty{r_1, \emptyword}\), \dots, \(r_n = x \in \delta\pqty{r_{n - 1}, \emptyword}\).

    But \(r \in \ecl\pqty{S}\), so there is some \(s \in S\) with length \(m\) sequence of \(\emptyword\)-transitions from \(s\) to \(r\). We put these together to get a sequence of \(\emptyword\)-transitions from \(s\) to \(x\), which means \(x \in S_{m + n} \pqty{s} \subseteq \ecl\pqty{s} \subseteq \ecl\pqty{S}\).
\end{proof}

An \(\emptyword\)-NFA has input \(w = \sigma_1 \cdots \sigma_k \in \Sigma\kstar\). From \(q_0\), it moves to all states in \(\ecl\pqty{q_0}\) and only then reads \(\sigma_1\). For each \(x \in \ecl\pqty{q_0}\), it takes the set of states \(\delta\pqty{x, \sigma_1}\), and for each \(y_x \in \delta\pqty{x, \sigma_1}\), it goes to \(\ecl\pqty{y_x}\), and the automaton is now in the set these states, union over all \(y_x\) over all such \(x\). We continue this until the word \(w\) is read, then \(w\) is accepted if any of the end states is an accept state, and rejected otherwise.

\begin{definition}[Extended Transition Function (\(\emptyword\)-NFA)]
    The \term{extended transition function} of an \(\emptyword\)-NFA \(E\) is given by
    \[
        \functiondomain{\hat{\delta}}{Q \times \Sigma\kstar}{\powerset\pqty{Q}}
    \]
    defined inductively by
    \begin{itemize}
        \item the empty word \(\hat{\delta} \pqty{q, \epsilon} = \ecl\pqty{q}\),
        \item a one-character word
        \[
            \hat{\delta} \pqty{q, \sigma} = \ecl\pqty{\bigcup_{p \in \ecl\pqty{q}} \delta\pqty{p, \sigma}},
        \]
        and
        \item the inductive step
        \[
            \hat{\delta} \pqty{q, \sigma_1 \ldots \sigma_k} = \ecl\pqty{\bigcup_{p \in \hat{\delta}\pqty{q, \sigma_1 \ldots \sigma_{k - 1}}} \delta\pqty{p, \sigma_k}}.
        \]
    \end{itemize}
\end{definition}

\subsection{Equivalence of DFAs, NFAs and \(\emptyword\)-NFAs}

Clearly, any DFA ``is'' an NFA by defining the new transition function
\[
    \delta'\pqty{q, \sigma} = \Bqty{\delta\pqty{q, \sigma}},
\]
and any NFA is an \(\emptyword\)-NFA, by extending transition for
\[
    \delta\pqty{q, \emptyword} = \emptyset
\]
such that \(\ecl\pqty{S} = S\) for all \(S\).

Underlying all this is, however, languages. Any regular language is the language of an (\(\emptyword\)-) NFA clearly by above.

\begin{definition}[Language Accepted by NFA/\(\emptyword\)-NFA]
    Let \(N\) be an NFA (or an \(\emptyword\)-NFA). The \term{language accepted by \(N\)}, denoted by \(\langacc\pqty{N}\), is the set of all words accepted by \(N\), i.e.,
    \[
        \langacc\pqty{N} = \set{w \in \Sigma\kstar}{\hat{\delta}\pqty{q_0, w} \cap F \neq \emptyset}.
    \]
\end{definition}

In fact, the converse is true as well, and we will show this by the \term{subset construction}. We will show this for NFAs first, and the idea for \(\emptyword\)-NFAs naturally follows.

Suppose now we have a NFA \(N\). We will produce a DFA \(D\) on the same alphabet \(\Sigma\), such that \(\langacc\pqty{N} = \langacc\pqty{D}\).

\begin{definition}[Subset Construction]
    \label{def:subset-construction}%
    For the NFA \(N = \pqty{Q, \Sigma, \delta, q_0, F}\), the \term{subset construction} for \(N\) produces the DFA \(D = \pqty{\powerset\pqty{Q}, \Sigma, \Delta, \Bqty{q_0}, \mathcal{F}}\), where the accept states are given by the set of subsets of states that contain at least one accept state of \(N\):
    \[
        \mathcal{F} = \set{S \subseteq Q}{S \cap F \neq \emptyset},
    \]
    and for \(S \subseteq Q, \sigma \in \Sigma\), we define
    \[
        \Delta\pqty{S, \sigma} = \bigcup_{q \in S} \delta\pqty{q, \sigma} \in \powerset\pqty{Q}.
    \]

    (Intuitively, \(\Delta\) gives the subset of states reached from \(S\) by following an edge labelled \(\sigma\).)
\end{definition}

\begin{theorem}[Equivalence of Subset Construction]
    \label{thm:subset-construction-equivalence}%
    For the NFA \(N\) and DFA \(D\) obtained from the subset construction as in \autoref{def:subset-construction}, and let \(\hat{\delta}\) and \(\hat{\Delta}\) be the respective extended transition functions. Then for all \(w \in \Sigma\kstar\), we have
    \[
        \hat{\Delta}\pqty{\Bqty{q_0}, w} = \hat{\delta}\pqty{q_0, w}.
    \]
\end{theorem}

\begin{proof}
    We prove by induction on the length \(k = \abs{w}\). Base case \(k = 0\) is \(w = \emptyword\), then
    \[
        \hat{\Delta}\pqty{\Bqty{q_0}, \emptyword} = \Bqty{q_0} = \hat{\delta}\pqty{q_0, \emptyword}.
    \]

    Now, suppose that
    \[
        \hat{\Delta} \pqty{\Bqty{q_0}, \sigma_1 \ldots \sigma_{k - 1}} = \hat{\delta}\pqty{q_0, \sigma_1 \ldots \sigma_{k - 1}}.
    \]

    Then, for \(w = \sigma_1 \ldots \sigma_{k - 1} \sigma_k\), we have
    \begin{align*}
        \hat{\delta} \pqty{q_0, w} &= \bigcup_{p \in \hat{\delta}\pqty{q_0, \sigma_1 \ldots \sigma_{k - 1}}} \delta\pqty{p, \sigma_k} && \text{by \autoref{def:extended-transition-function-nfa}}\\
        &= \Delta \pqty{\hat{\delta} \pqty{q_0, \sigma_1 \ldots \sigma_{k - 1}}, \sigma_k} && \text{by \autoref{def:subset-construction}}\\
        &= \Delta \pqty{\hat{\Delta} \pqty{\Bqty{q_0}, \sigma_1 \ldots \sigma_{k - 1}}, \sigma_k} && \text{by Induction Hypothesis} \\
        &= \hat{\Delta} \pqty{\Bqty{q_0}, w}. && \text{by \autoref{def:extended-transition-function-dfa}}
    \end{align*}
\end{proof}

\begin{corollary}[Equivalence of DFAs and NFAs]
    A language \(L\) is accepted by a DFA if and only if it is accepted by an NFA.
\end{corollary}

\begin{proof}
    If \(L\) is accepted by a DFA, then it is accepted by an NFA, since any DFA is an NFA.
    
    Conversely, if \(L\) is accepted by an NFA \(N\), then we can construct a DFA \(D\) from the subset construction. Then \(w\) is accepted by \(N\), if and only if
    \[
        \hat{\delta} \pqty{q_0, w} \cap F \neq \emptyset,
    \]
    which by \autoref{thm:subset-construction-equivalence} is if and only if
    \[
        \hat{\Delta} \pqty{\Bqty{q_0}, w} \in \mathcal{F},
    \]
    which is if and only if \(w\) is accepted by \(D\).
\end{proof}

\begin{definition}[Subset Construction with \(\emptyword\)-Transitions]
    \label{def:subset-construction-with-epsilon-transitions}%
    For the \(\emptyword\)-NFA \(E = \pqty{Q, \Sigma, \delta, q_0, F}\), the \term{subset construction with \(\emptyword\)-transitions} for \(E\) produces the DFA \(D = \pqty{\powerset\pqty{Q}, \Sigma, \Delta, \ecl\pqty{q_0}, \mathcal{F}}\), where the accept states are
    \[
        \mathcal{F} = \set{S \subseteq Q}{S \cap F \neq \emptyset},
    \]
    as before, and for \(S \subseteq Q, \sigma \in \Sigma\), we define
    \[
        \Delta\pqty{S, \sigma} = \ecl\pqty{\bigcup_{q \in S} \delta\pqty{q, \sigma}}.
    \]

    (Intuitively, \(\Delta\) gives the subset of states reached from \(S\) by following an edge labelled \(\sigma\), and then taking all possible \(\emptyword\)-transitions.)
\end{definition}

\begin{theorem}[Equivalence of \(\emptyword\)-NFAs and DFAs]
    For a given \(\emptyword\)-NFA \(E\) and the DFA \(D\) obtained from the subset construction with \(\emptyword\)-transitions as in \autoref{def:subset-construction-with-epsilon-transitions}, and let \(\hat{\delta}\) and \(\hat{\Delta}\) be the respective extended transition functions. Then for all \(w \in \Sigma\kstar\), we have
    \[
        \hat{\Delta}\pqty{\ecl\pqty{q_0}, w} = \hat{\delta}\pqty{q_0, w}.
    \]
\end{theorem}

\begin{proof}
    The proof is near-identical to the proof of \autoref{thm:subset-construction-equivalence}. In particular, for the induction step, we start with \(\hat{\delta}\pqty{q_0, w}\) and apply \autoref{def:extended-transition-function-nfa}, \autoref{def:extended-transition-function-dfa}, the induction hypothesis, and \autoref{def:extended-transition-function-dfa}, eventually reaching \(\hat{\Delta}\pqty{\ecl\pqty{q_0}, w}\).
\end{proof}

\begin{corollary}[Equivalence of DFAs, NFAs and \(\emptyword\)-NFAs]
    \label{cor:equivalence-of-dfas-nfas-and-epsilon-nfas}%
    A language \(L\) is accepted by some DFA, if and only if it is accepted by some NFA, if and only if it is accepted by some \(\emptyword\)-NFA.
\end{corollary}

\subsection{Regular Expressions}

The natural question is, why bother? If they are all equivalent in terms of the languages they accept, why do we need to consider NFAs and \(\emptyword\)-NFAs? We now give an algebraic/symbolic description of a regular language, which is known as a \term{regular expression}. We will then show the set of languages defined by DFAs is the same as the set of languages defined by regular expressions, and hence the set of languages defined by (\(\emptyword\)-)NFAs, and they are all equivalent.

\begin{definition}[New Languages from Old Languages]
    We define the following.

    \begin{enumerate}[label=(\arabic*)]
        \item The \term{union} of two languages \(L\) and \(M\) over \(\Sigma_L\) and \(\Sigma_M\) respectively is the language \(L \cup M\) over the alphabet \(\Sigma_L \cup \Sigma_M\).
        \item The \term{concatanation} of two languages \(L\) and \(M\) over \(\Sigma_L\) and \(\Sigma_M\) respectively is the language
        \[
            LM = \set{vw \in \pqty{\Sigma_L \cup \Sigma_M}\kstar}{v \in L, w \in M}.
        \]

        (Clearly \(LM \neq ML\) in general.)

        \item The \term{closure} \(L\kstar\) of a language \(L\) over \(\Sigma_L\) is the set of all words formed by concatenating zero or more words from \(L\) (not necessarily distinct), i.e.,
        \[
            L\kstar = \bigcup_{k = 0}^{\infty} L^k \ni \emptyword.
        \]
    \end{enumerate}
\end{definition}

\begin{remark}
    For \(n \geq 2\), we can have \(L \nsubseteq L^n\), if \(\emptyword \notin L\), but this does not happen if \(\emptyword \in L\) (in which case \(L^n\) will be an increasing chain of sets). However, certainly we have \(L \subseteq L\kstar\).
\end{remark}

\begin{definition}[Regular Expressions]
    A \term{regular expression} \(R\) is a finite string of symbols denoting a language \(\langacc\pqty{R}\) over some alphabet, built up from the following inductive rules.

    \begin{enumerate}[label=(\arabic*)]
        \item Both \(\emptyword\) and \(\emptyset\) are regular expressions, with \(\langacc\pqty{\emptyword} = \Bqty{\emptyword}\) and \(\langacc\pqty{\emptyset} = \emptyset\).
        \item If \(a\) is a symbol (but not \(\emptyword\), \(\emptyset\), \((\), \()\), \({}\kstar\), \(+\)), then \(a\) is a regular expression with \(\langacc\pqty{a} = \Bqty{a}\).
        \item If \(E\) and \(F\) are regular expressions, then:
        \begin{itemize}
            \item \(E + F\) is a regular expression denoting the union, so \(\langacc\pqty{E + F} = \langacc\pqty{E} \cup \langacc\pqty{F}\).
            \item \(EF\) is a regular expression denoting the concatenation, so \(\langacc\pqty{EF} = \langacc\pqty{E}\langacc\pqty{F}\).
            \item \(E\kstar\) is a regular expression denoting the closure, so \(\langacc\pqty{E\kstar} = \langacc\pqty{E}\kstar\).
            \item \(\pqty{E}\) is a regular expression with the same language as \(E\), so \(\langacc\pqty{\pqty{E}} = \langacc\pqty{E}\).
        \end{itemize}
    \end{enumerate}
\end{definition}

\begin{definition}[Order of Precedence for Regular Expressions]
    The order of precedence for regular expressions is as follows:
    \begin{enumerate}[label=(\arabic*)]
        \item \(\pqty{E}\) has the highest precedence.
        \item \(\kstar\) has the next highest precedence.
        \item Concatenation has the next highest precedence.
        \item \(+\) has the lowest precedence.
    \end{enumerate}
\end{definition}

\begin{examples*}
    \begin{itemize}
        \item The regular expression \(0 1\kstar + 1\) is \(\pqty{0 \pqty{1\kstar}} + \pqty{1}\) is the union of the language \(\Bqty{0, 01, 011, 0111, \ldots}\) and the language \(\Bqty{1}\), which is \(\Bqty{0, 01, 011, 0111, \ldots, 1}\).
        \item The regular expression \(0 + 1\) accepts \(\Bqty{0, 1}\), \(0 + 0\) accepts \(\Bqty{0}\).
        \item The regular expression \(\pqty{1 + \epsilon}\pqty{01}\kstar \pqty{0 + \epsilon}\) accepts all strings where \(0\) and \(1\) alternate, including the empty string.
        \item The regular expression \(\pqty{0 + 1}^3\) are the eight words over \(\Bqty{0, 1}\) of length \(3\).
    \end{itemize}
\end{examples*}

\subsection{Regular Expressions define Regular Languages}

\begin{theorem}[Regular Expressions define \(\emptyword\)-NFAs]
    For any regular expression \(R\), there exists a \(\emptyword\)-NFA \(E\) such that \(\langacc\pqty{R} = \langacc\pqty{E}\).
\end{theorem}


\begin{proof}
    We build \(E\) up by induction. All \(\emptyword\)-NFAs constructed will be such that:
    \begin{itemize}
        \item there is a \emph{unique} accepting state,
        \item there is no directed edges into the start state, and
        \item there is no directed edges out of accepting state.
    \end{itemize}

    Then we construct \(\emptyword\)-NFAs inductively as follows.

    \begin{enumerate}[label=(\arabic*)]
        \item For the base case, we have the following \(\emptyword\)-NFAs for the regular expressions \(\emptyset\), \(\emptyword\) and \(a\):
        
        \begin{center}
            \begin{tikzpicture}[->,>=Stealth,shorten >=1pt,auto,node distance=1cm,semithick,initial text=]
                \node[state, initial] (q0)  {};
                \node[state, accepting] (q1)  [right=of q0] {};
            \end{tikzpicture}
            \hspace{1cm}
            \begin{tikzpicture}[->,>=Stealth,shorten >=1pt,auto,node distance=1cm,semithick,initial text=]
                \node[state, initial] (q0)  {};
                \node[state, accepting] (q1)  [right=of q0] {};
                \path (q0) edge node {\(\emptyword\)} (q1);
            \end{tikzpicture}
            \hspace{1cm}
            \begin{tikzpicture}[->,>=Stealth,shorten >=1pt,auto,node distance=1cm,semithick,initial text=]
                \node[state, initial] (q0)  {};
                \node[state, accepting] (q1)  [right=of q0] {};
                \path (q0) edge node {\(a\)} (q1);
            \end{tikzpicture}
        \end{center}

        \item For the inductive step. suppose we have a regular expression \(R, S\) with \(\emptyword\)-NFAs \(E, F\), with \(\langacc\pqty{E} = \langacc\pqty{R}\) and \(\langacc\pqty{F} = \langacc\pqty{S}\). (We will denote this by a zig-zag arrow labelling \(R\) or \(S\).) Then we can construct \(\emptyword\)-NFAs for \(R + S\), \(RS\) and \(R\kstar\) as follows.
        \begin{itemize}
            \item An \(\emptyword\)-NFA for \(R + S\) is given by:
            
            \begin{center}
                \begin{tikzpicture}[->,>=Stealth,shorten >=1pt,auto,node distance=1.5cm,semithick,initial text=]
                    \node[state, initial] (q0) {};
                    \node[state] (r0)  [above right=of q0] {};
                    \node[state] (r1)  [right=of r0] {};
                    \node[state] (s0)  [below right=of q0] {};
                    \node[state] (s1)  [right=of s0] {};
                    \node[state, accepting] (q1)  [below right=of r1] {};
                    \path (q0) edge node {\(\emptyword\)} (r0)
                        (q0) edge node[swap] {\(\emptyword\)} (s0)
                        (r0) edge[zigzag edge] node {\(R\)} (r1)
                        (s0) edge[zigzag edge] node[swap] {\(S\)} (s1)
                        (r1) edge node {\(\emptyword\)} (q1)
                        (s1) edge node[swap] {\(\emptyword\)} (q1);
                \end{tikzpicture}
            \end{center}

            If a word is input, then it can move through the first \(\emptyword\)s, but can only get through if and only if it is in either \(\langacc\pqty{R}\) or \(\langacc\pqty{S}\).

            \item An \(\emptyword\)-NFA for \(RS\) is given by:
            
            \begin{center}
                \begin{tikzpicture}[->,>=Stealth,shorten >=1pt,auto,node distance=1.5cm,semithick,initial text=]
                    \node[state, initial] (q0)  {};
                    \node[state] (r0)  [right=of q0] {};
                    \node[state] (r1)  [right=of r0] {};
                    \node[state] (s0)  [right=of r1] {};
                    \node[state] (s1)  [right=of s0] {};
                    \node[state, accepting] (q1)  [right=of s1] {};
                    \path (q0) edge node {\(\emptyword\)} (r0)
                        (r0) edge[zigzag edge] node {\(R\)} (r1)
                        (r1) edge node {\(\emptyword\)} (s0)
                        (s0) edge[zigzag edge] node {\(S\)} (s1)
                        (s1) edge node {\(\emptyword\)} (q1);
                \end{tikzpicture}
            \end{center}

            \item An \(\emptyword\)-NFA for \(R\kstar\) is given by:
            
            \begin{center}
                \begin{tikzpicture}[->,>=Stealth,shorten >=1pt,auto,node distance=1.5cm,semithick,initial text=]
                    \node[state, initial] (q0)  {};
                    \node[state] (r0)  [right=of q0] {};
                    \node[state] (r1)  [right=of r0] {};
                    \node[state, accepting] (q1)  [right=of r1] {};
                    \path (q0) edge node {\(\emptyword\)} (r0)
                        (q0) edge [bend left=30] node {\(\emptyword\)} (q1)
                        (r0) edge[zigzag edge] node {\(R\)} (r1)
                        (r1) edge node {\(\emptyword\)} (q1)
                        (r1) edge [bend left=30] node {\(\emptyword\)} (r0);
                \end{tikzpicture}
            \end{center}
        \end{itemize}
    \end{enumerate}
\end{proof}

\begin{theorem}[DFAs define Regular Expressions]
    For any DFA \(D\), there exists a regular expression \(R\) such that \(\langacc\pqty{D} = \langacc\pqty{R}\).
\end{theorem}

\begin{proof}
    Given \(D = \pqty{Q, \Sigma, \delta, q_0, F}\), label the states by \(Q = \Bqty{1, 2, \ldots, n}\), and say the start state \(q_0\) is labelled by \(1\). Now, given two states \(1 \leq i, j \leq n\) and \(0 \leq k \leq n\) inclusive, we construct by induction on \(k\) a regular expression \(R_{ij}^{\pqty{k}}\), consisting of exactly the words \(w\) over \(\Sigma\) that begin at state \(i\) and end at state \(j\), and such that all the intermediate states passed through (excluding the endpoints) are labelled by numbers at most \(k\). In other words, we think of a given word \(w\) as a directed path from \(i\) to \(j\).

    For \(k = 0\), this does not allow for any intermediate states, and we have to go directly from \(i\) to \(j\). So we let \(\Bqty{a_1, \ldots, a_l}\) be all the symbols that label an edge from \(i\) to \(j\) (if there are no such edges, then \(l = 0\)), and we set
    \[
        R_{ij}^{\pqty{0}} = \begin{cases}
            a_1 + \cdots + a_l, & l > 0,\\
            \emptyset, & l = 0.
        \end{cases}
    \]
    if \(i \neq j\), and if \(i = j\), let 
    \[
        R_{ii}^{\pqty{0}} = \begin{cases}
            a_1 + \cdots + a_l + \emptyword, & l > 0,\\
            \emptyword, & l = 0.
        \end{cases}
    \]
    using \(\emptyword\) for no move.

    Suppose now that \(R_{ij}^{\pqty{t}}\) is defined for all \(t < k\). Given a path \(\pi\) from \(i\) to \(j\) not passing through the stats \(k + 1, \ldots, n\). Either:
    \begin{enumerate}
        \item The path \(\pi\) does not pass through state \(k\) either. Then \(\pi\) is accepted by the regular expression \(R_{ij}^{\pqty{k - 1}}\).
        \item The path \(\pi\) passes through \(k\) various times, so we split the path as
        \[
            \pi = \sigma \pi_1 \pi_2 \ldots \pi_r \omega
        \]
        where \(\sigma\) brings us from \(i\) to \(k\) without passing through \(k\), \(\pi_1, \ldots, \pi_r\) are paths from \(k\) to \(k\) without passing through \(k\), and \(\omega\) is a path from \(k\) to \(j\) without passing through \(k\).

        \begin{center}
            \begin{tikzpicture}[>=Stealth,node distance=3cm,auto]
                \node[state] (i) {\(i\)};
                \node[state] (k) [right of=i] {\(k\)};
                \node[state] (j) [right of=k] {\(j\)};

                \path[->]
                    (i) edge node {\(\sigma\)} (k)
                    (k) edge node {\(\omega\)} (j)
                        edge[loop above] node {\(\pi_1\)} ()
                        edge[loop below] node {\(\pi_2\)} ();
            \end{tikzpicture}
        \end{center}

        We know \(\sigma \in \langacc\pqty{R_{ik}^{\pqty{k - 1}}}\), and \(\pi_1, \ldots, \pi_r \in \langacc\pqty{R_{kk}^{\pqty{k - 1}}}\), and \(\omega \in \langacc\pqty{R_{kj}^{\pqty{k - 1}}}\).

        So the word read from \(\pi\) is in the language given by the regular expression
        \[
            R_{ik}^{\pqty{k - 1}} \pqty{R_{kk}^{\pqty{k - 1}}}\kstar R_{kj}^{\pqty{k - 1}}.
        \]
    \end{enumerate}

    Then for the two cases, we define
    \[
        R_{ij}^{\pqty{k}} = R_{ij}^{\pqty{k - 1}} + R_{ik}^{\pqty{k - 1}} \pqty{R_{kk}^{\pqty{k - 1}}}\kstar R_{kj}^{\pqty{k - 1}}.
    \]

    Finally, if \(F = \Bqty{j_1, \ldots, j_s}\) (and the start state is \(1\)), then the language that \(D\) accepts is given by the regular expression
    \[
        R = R_{1 j_1}^{\pqty{n}} + \cdots + R_{1 j_s}^{\pqty{n}},
    \]
    with \(\langacc\pqty{D} = \langacc\pqty{R}\). This finishes the construction as desired.
\end{proof}

\subsection{Closure Properties}

\begin{theorem}[Closure Properties of Regular Languages]
    Let \(L, M\) be regular languages over \(\Sigma_L\) and \(\Sigma_M\) respectively. Then the following are also regular languages:
    \begin{enumerate}[label=(\arabic*)]
        \item \(L \cup M\) over \(\Sigma_L \cup \Sigma_M\),
        \item \(LM\) over \(\Sigma_L \cup \Sigma_M\),
        \item \(L\kstar\) over \(\Sigma_L\).
    \end{enumerate}
\end{theorem}

\begin{proof}
    We consider regular expressions \(R_L\) and \(R_M\) so \(\langacc\pqty{R_K} = L\) and \(\langacc\pqty{R_M} = M\). Then we have
    \begin{enumerate}[label=(\arabic*)]
        \item \(R_L + R_M\) is a regular expression with \(\langacc\pqty{R_L + R_M} = L \cup M\).
        \item \(R_L R_M\) is a regular expression with \(\langacc\pqty{R_L R_M} = LM\).
        \item \(R_L\kstar\) is a regular expression with \(\langacc\pqty{R_L\kstar} = L\kstar\).
    \end{enumerate}
\end{proof}

\begin{theorem}[Complement of Regular Languages]
    Let \(L\) be a regular language over \(\Sigma\). Then the \term{complement} \(\overline{L} = \Sigma\kstar \setminus L\) is also a regular language.
\end{theorem}

\begin{proof}
    Given a DFA \(D\) with \(L = \langacc\pqty{D}\), consider the DFA \(\overline{D}\) which is same as \(D\) but with accept spaces \(Q \setminus F\) (the non-accept states of \(D\)). Then for any \(w \in \Sigma\kstar\), we have
    \[
        w \in \overline{L} \iff w \notin L \iff \hat{\delta} \pqty{q_0, w} \notin F \iff \hat{\delta} \pqty{q_0, w} \in Q \setminus F \iff w \in \langacc\pqty{\overline{D}}.
    \]
    as the extended transition function is the same for both \(D\) and \(\overline{D}\).
\end{proof}

\begin{corollary}[Intersection of Regular Languages]
    If \(L, M\) are regular languages over \(\Sigma_L\) and \(\Sigma_M\) respectively, then the intersection \(L \cap M\) is also a regular language over \(\Sigma_L \cap \Sigma_M\).
\end{corollary}

\begin{proof}
    We notice that
    \[
        L \cap M = \overline{\overline{L} \cup \overline{M}}.
    \]
\end{proof}

\subsection{The Pumping Lemma}

How do we show a given language is \emph{not} regular? Clearly,
\begin{itemize}
    \item any finite language is regular;
    \item as \(\Sigma^n\) is a finite set, so if \(L\) is infinite then there is some \(w \in L\) such that \(\abs{w} > n\).
\end{itemize}

Suppose a word \(w\) is accepted by a DFA \(D\) but \(\abs{w} \geq \abs{Q}\), i.e. \(w\) has no fewer symbols than \(D\) has states. Then \(w\) defines a directed path in the transition diagram \(\Gamma_D\), which must visit some state at least twice. So we can write
\[
    w = xyz
\]
for subwords \(x, y\) and \(z\), where \(y\) gives us the ``loop'' and  then go around the loop again, or not at all.

\begin{theorem}[Pumping Lemma for Regular Languages]
    \label{thm:pumping-lemma-for-regular-languages}%
    If \(L\) is a regular language, then there exists a constant \(n \geq 1\) (a \term{pumping number}) such that for any word \(w \in L\) with \(\abs{w} \geq n\), we can write
    \[
        w = xyz
    \]
    for subwords \(x, y, z\) such that
    \begin{enumerate}[label=(\arabic*)]
        \item \(y \neq \emptyword\) (although \(x\) and \(z\) could be),
        \item \(\abs{xy} \leq n\), and
        \item \(xy^k z \in L\) for all \(k \geq 0\).
    \end{enumerate}

    Note \(k = 1\) retrieves \(w\), \(k = 0\) is \term{pumping down}, and \(k \geq 2\) is \term{pumping up}.
\end{theorem}

\begin{remark}
    The morale is, we can keep repeating (pumping) appearances of \(y\) in a regular language -- but not all languages have this property, and to show that a language is not regular, it would be useful to show that a language does not have this property.
\end{remark}
