\section{Context-Free Grammars}
\subsection{Grammars and Languages}

\begin{definition}[Production/Rewrite Rule, Rewrite System]
    Given an alphabet \(\Omega\), a \term{production/rewrite rule} is an element \(\pqty{\alpha, \beta}\) of \(\Omega\kplus \times \Omega\kstar\), written as \(\alpha \prodrule \beta\), interpreted as ``replace \(\alpha\) with \(\beta\)''.

    A \term{rewrite system} \(\pqty{\Omega, P}\) is an alphabet \(\Omega\) and a finite set \(P\) of rewrite rules.
\end{definition}

Think of this as if \(w \in \Omega\kplus\) contains \(\alpha\) as a substring, so \(w = \gamma \alpha \delta\). Then we can \emph{choose} to replace \(\alpha\) with \(\beta\), changing \(w\) to \(\gamma \beta \delta\).

\begin{remark}
    We require \(\alpha \neq \emptyword\), but we allow \(\alpha \prodrule \emptyword\). This is known as an \term{\(\emptyword\)-production}.
\end{remark}

\begin{example*}
    Consider a group \(G = \angBrac{a, b}\) and \(\Omega = \set{a, b, A, B}\). Then for any \(w \in \Omega\kplus\) containing \(bB\), applying a rewrite rule \(bB \prodrule \emptyword\) changes \(w\), but does not change the group element represented by \(w\) in \(G\).
    
    We can have the rewrite system
    \[
        P = \set{aA \prodrule \emptyword, bB \prodrule \emptyword, Bb \prodrule \emptyword, Aa \prodrule \emptyword}.
    \]
    
    This is related to the idea of \term{group presentations} and \term{free groups}.
\end{example*}

\begin{notation}
    We often use capitals for non-terminals, lowercase for terminals, and lowercase Greek for words over \(\Omega\).
\end{notation}

But where is the language?

\begin{definition}[Variable-Based Grammar, Derivation]
    A \term{(variable-based) grammar} \(G = \pqty{\Sigma, N, P, S}\) is a rewrite system where:
    \begin{itemize}
        \item \(\Omega = \Sigma \sqcup N\) is divided into \term{terminal letters} \(\Sigma\) and \term{non-terminal letters/variables} \(N\);
        \item Any production rule \(\pqty{\alpha \prodrule \beta} \in P\) only has non-terminals on the left-hand side, i.e. \(\alpha \in N\kplus\), and \(P \subseteq N\kplus \times \Omega\kstar\);
        \item \(S \in N\) is a single \term{start symbol}.
    \end{itemize}

    For a grammar \(G = \pqty{\Sigma, N, P, S}\) and \(\alpha, \beta \in \Omega\kstar\), we say
    \begin{enumerate}[label=(\roman*)]
        \item \term{\(\beta\) is derivable from \(\alpha\) in one step} if \(\alpha = \alpha_1 \gamma \alpha_2\), \(\beta = \alpha_1 \delta \alpha_2\), and \(\pqty{\gamma, \delta} \in P\), written as \(\alpha \prodrule[1][G] \beta\).
        \item \term{A derivation of length \(n\) of \(\beta\) from \(\alpha\)}, written \(\alpha \prodrule[n][G] \beta\), is inductively defined as there exists some \(\gamma\) with \(\alpha \prodrule[n-1][G] \gamma\) and \(\gamma \prodrule[1][G] \beta\). Where \(n = 0\), we have \(\alpha \prodrule[0][G] \alpha\).
        \item \term{\(\beta\) is derivable from \(\alpha\)}, denotes as \(\alpha \prodrule[\ast][G] \beta\) means that there is some \(n \in \NN\), such that \(\alpha \prodrule[n][G] \beta\).
        \item A word \(w \in \Omega\kstar\) derivable for start symbol \(S\) is in \term{sequential form}.
        \item A word in sequential form is a \term{sentence}, if \(w \in \Sigma\kstar\) consists of only terminals.
    \end{enumerate}
\end{definition}

\begin{definition}[Language Generated by a Grammar]
    The \term{language generated by a grammar \(G\)} is the set
    \[
        \langacc\pqty{G} = \set{w \in \Sigma\kstar}{S \prodrule[\ast][G] w}.
    \]

    This is the set of all sentences derivable in \(G\) from the start symbol \(S\).
\end{definition}

\begin{remark}
    In general, a word \(w \in \langacc\pqty{G}\) could have many derivations from \(S\), of same or even different lengths. Also, we can have grammars \(G_1 \neq G_2\) with \(\langacc\pqty{G_1} = \langacc\pqty{G_2}\).

    For example, if we have a non-terminal character \(X \neq S\) not appearing in the right-hand side of any production rule \(\alpha \prodrule \beta \in P\). Then \(X\) never appears in any derivation from \(S\), so we can add \(X \prodrule \emptyword\) to \(P\) which is never used.
\end{remark}

The \term{Chomsky hierarchy} classifies grammars and languages as below.

\begin{definition}[Type of Production Rule, Grammar and Language]
    A production rule \(\pqty{\alpha, \beta} \in \Omega\kplus \times \Omega\kstar\) is of:
    \begin{itemize}
        \item \term{Type 0} if \(\alpha \in N\kplus\);
        \item \term{Type 1 (Noncontracting)} if \(\alpha \in N\kplus\) and \(\abs{\alpha} \leq \abs{\beta}\);
        \item \term{Type 2} if \(\alpha = A \in N\) and \(\abs{\beta} \geq 1\);
        \item \term{Type 3} if \(\alpha = A \in N\) and \(\beta = a\) or \(\beta = aB\) for \(B \in N\) and \(a \in \Sigma\).
    \end{itemize}

    A \term{grammar} is of \term{type \(i\)} if all its production rules are of type \(i\). A \term{language} is of \term{type \(i\)} if it is generated by some grammar of type \(i\).
\end{definition}

\begin{remark}
    A grammar of type 0 is any variable-based grammar.
\end{remark}

Suppose \(L\) is of type 1 over \(\Sigma\) and we are given \(w \in L\). Then there exists a derivation in type 1 grammar \(G\), such that
\[
    \beta_0 = S \prodrule[1][G] \beta_1 \prodrule[1][G] \beta_2 \prodrule[1][G] \cdots \prodrule[1][G] \beta_n = w,
\]
and we take the shortest such derivation, with length \(m\).

But \(\abs{\beta_i} \leq \abs{\beta_{i + 1}}\), and if \(l = \abs{\beta_i} = \cdots = \abs{\beta_{i + j}}\) for \(j \geq \abs{\Omega}^l\), then two of these \(\beta\)s are the same by the pigeonhole principle, so \(m\) must not be minimal.

The, we have
\[
    m \leq \sum_{l = 1}^{\abs{w}} \abs{\Omega}^l = M
\]
so we can tell whether or not \(w \in L = \langacc\pqty{G}\) systematically by creating all derivations of length at most \(M\) from \(S\).

If \(\emptyword \in \langacc\pqty{G}\), then we need some \(\emptyword\)-production \(\alpha \prodrule \emptyword\), so languages of type 1 (and hence, of 2 and 3) do \emph{not} contain the empty word.

\subsection{Context-Free Languages}

\begin{definition}[Context-Free Grammar and Language]
    A \term{context-free grammar} (CFG) \(G = \pqty{N, \Sigma, P, S}\) is where every production rule is of the fom \(\pqty{A, \alpha} \in N \times \Omega\kstar\), i.e., a type 2 grammar but also allowing \(\alpha = \emptyword\). A \term{language} \(L\) is a \term{context-free language} (CFL) if it is generated by some context-free grammar.
\end{definition}

\begin{examples}[Context-Free Languages]
    \begin{enumerate}[label=(\roman*)]
        \item If a language \(L\) is of type 2, then it is context-free.
        \item Let \(N = \set{S}\) and \(\Sigma = \set{a, b}\), with production rules \(S \prodrule aSb\) and \(S \prodrule \emptyword\) which we denote as \(S \prodrule aSm \mid \emptyword\). Then we obtain a CFL \(\emptyword, ab, aabb, \ldots, a^n b^n, \ldots\), which is \emph{not} regular!
        \item All regular languages are context-free.
        \item Consider the production rule
        \[
            S \prodrule SaSbS \mid SbSaS \mid \emptyword.
        \]

        We get words with the same number of \(a\)s and \(b\)s.
        \item For \(w = \sigma_1 \cdots \sigma_n \in \Sigma\kstar\), the \term{reverse} of \(w\) is \(R\pqty{w} = \sigma_n \cdots \sigma_1 \in \Sigma\kstar\). The set of palindromes
        \[
            X = \set{w \in \set{a, b}\kstar}{R\pqty{w} = w}
        \]
        is a CFL. It is generated by the production rules
        \[
            S \prodrule aSa \mid bSb \mid a \mid b \mid \emptyword.
        \]

        The first two production rules give symmetry ``from the middle'', and the next to finish it off if the final length is odd, and the empty word finishes it off if the final length is even.
    \end{enumerate}
\end{examples}

\begin{definition}[Language of Balanced Parentheses]
    Let \(\Sigma = \set{[, ]}\). For \(w \in \Sigma\kstar\), let \(L\pqty{w}\) be the number of \([\)s in \(w\) and \(R\pqty{w}\) be the number of \(]\)s in \(w\). We say \(w\) is \term{balanced} if \(L\pqty{w} = R\pqty{w}\) and for all \(x \in \Sigma\kstar\) with \(w = xy\), we have \(L\pqty{x} \geq R\pqty{x}\).
\end{definition}

\begin{proposition}[Grammar of Balanced Parentheses]
    \label{prop:balanced-parentheses}%
    The CFG \(G\) with production rule
    \[
        S \prodrule[][] [S] \mid SS \mid \emptyword
    \]
    has \(\langacc\pqty{G}\) as the language of all balanced words in \(\Sigma\kstar\). This is \emph{not} regular.
\end{proposition}

\subsection{Chomsky Normal Form}

The idea is that we can convert any CFG into a standard form, with longer (more) but simpler (shorter) production rule, with the same language (except we will be missing the empty word).

\begin{definition}[Chomsky Normal Form]
    A context-free grammar \(G = \pqty{N, \Sigma, P, S}\) is in \term{Chomsky normal form} (CNF) if every production rule is of the form \(A \prodrule a\) or \(A \prodrule BC\) for \(A, B, C \in N\) and \(a \in \Sigma\).
\end{definition}

\begin{example}
    \label{ex:brackets-in-disguise}%
    The production rules
    \begin{align*}
        S &\prodrule AB \mid AC \mid SS \\
        C &\prodrule SB \\
        A &\prodrule a \\
        B &\prodrule b
    \end{align*}
    is in CNF.
\end{example}

\begin{definition}[\(\emptyword\)-Production, Unit Production]
    Let \(G = \pqty{N, \Sigma, P, S}\) be a CFG.

    \begin{enumerate}[label=(\roman*)]
        \item An \term{\(\emptyword\)-production} is one of the form \(A \prodrule \emptyword\) for some \(A \in N\).
        \item A \term{unit production} is one of the form \(A \prodrule B\) for some \(A, B \in N\).
    \end{enumerate}
\end{definition}

We first show that we can modify a CFG to remove the above two types of production rules, while keeping the same language (except for the empty word).

\begin{theorem}[Removing \(\emptyword\)-Productions and Unit Productions]
    \label{thm:remove-empty-unit}%
    Let \(G\) be a CFG as above. Then we can construct a CFG \(\mathring{G} = \pqty{N, \Sigma, \mathring{P}, S}\) with no \(\emptyword\)-productions or unit productions, such that \(\langacc\pqty{\mathring{G}} = \langacc\pqty{G} \setminus \set{\emptyword}\).
\end{theorem}

This means that type-2 languages are equivalent to CFLs up to the empty word.

\begin{proof}
    Given the productions \(P\) of \(G\), let \(\hat{P}\) be the smallest set of productions with \(P \subseteq \hat{P}\) and closed uder:
    \begin{enumerate}[label=(\arabic*)]
        \item If \(A \prodrule \alpha B \beta\) and \(B \prodrule \emptyword\) are in \(\hat{P}\), then \(A \prodrule \alpha \beta\) is in \(\hat{P}\).
        \item If \(A \prodrule B\) and \(B \prodrule \gamma\) are in \(\hat{P}\), then \(A \prodrule \gamma\) is in \(\hat{P}\).
    \end{enumerate}

    To show that \(\hat{P}\) is a finite set, we start with a finite set \(P\), and add all types of (1) and (2) if both are in \(\hat{P}\). At each stage, any added production rule has right-hand side no longer than existing productions, so we terminate, as there is a finite number of possible right-hand sides.

    Let \(\hat{G}\) be the CFG \(G = \pqty{N, \Sigma, \hat{P}, S}\). As \(P \subseteq \hat{P}\), we have \(\langacc\pqty{G} \subseteq \langacc\pqty{\hat{G}}\). But for any \(w \in \langacc\pqty{\hat{G}}\), a derivation of \(w\) from \(S\) in \(\hat{P}\) can be replaced by one where all the productions are obtained at the previous stage, and so on, back to \(P\). So we have \(\langacc\pqty{\hat{G}} = \langacc\pqty{G}\).

    We now show we can remove all \(\emptyword\) and unit productions from \(\hat{P}\) to get our desired \(\mathring{P}\) without changing \(\langacc\pqty{\hat{G}}\), apart from losing the emptyword. For any \(w \in \langacc\pqty{\hat{G}}\) with \(w \neq \emptyword\), take a minimum length derivation of \(w\) from \(S\) which is \(S \prodrule[\ast][\hat{G}] w\).
    
    Suppose an \(\emptyword\)-production \(B \prodrule \emptyword\) is used in this derivation. Then
    \[
        S \prodrule[\ast][\hat{G}] \gamma B \delta \prodrule[1][\hat{G}] \gamma \delta \prodrule[\ast][\hat{G}] w,
    \]
    where \(\gamma, \delta \in \Omega\kstar\).

    Given a production rule \(\alpha \prodrule[1][\hat{G}] \beta\) using \(\pqty{A, \pi}\) and a particular appearance of a non-terminal \(X\) in \(\beta\), say \(X\) is \term{new} if it is in \(\pi\). For example, if our rule reads \(\pqty{B, BAB}\) and we have
    \[
        BA\boxed{B} \prodrule[1] \underline{B}A\mathbf{B}A\mathbf{B}
    \]
    where we replace the boxed \(B\), the bold \(B\)s are new, and the underlined \(B\) is not new.

    Consider the point at which this particular \(B\) is new (\(B\) is not original start symbol \(S\) as that's replace immediately -- this breaks down for the empty word) coming from some production \(A \prodrule \alpha B \beta\) in \(hat{G}\), i.e., the process will be
    \[
        S \prodrule[m] \eta A \theta \prodrule[1] \eta \alpha B \beta \theta \prodrule[n] \gamma B \delta \prodrule[1] \gamma \delta \prodrule[k] w
    \]
    but we know \(A \prodrule \alpha \beta\) is also in \(\hat{G}\), so we can shorten this to

    \[
        S \prodrule[m] \eta A \theta \prodrule[1] \eta \alpha \beta \theta \prodrule[n] \gamma\delta \prodrule[k] w,
    \]
    and this is valid because \(B\) is untouched within the \(n\) steps in the middle.

    Now, suppose we use a unit production rule
    \[
        S \prodrule[\ast] \alpha A \beta \prodrule[1] \alpha B \beta \prodrule[\ast] w
    \]
    is a derivation of minimal length. Eventually, as \(B \in N\), we have \(B\) is replaced with \(B \prodrule \gamma\), say
    \[
        S \prodrule[m] \alpha A \beta \prodrule[1] \alpha B \beta \prodrule[n] \eta B \theta \prodrule[1] \eta \gamma \theta \prodrule[k] w.
    \]

    But we have \(A \prodrule \gamma\) in \(\hat{G}\), so we can shorten this to
    \[
        S \prodrule[m] \alpha A \beta \prodrule[1] \alpha \gamma \beta \prodrule[n] \eta \gamma \theta \prodrule[k] w,
    \]
    and this is valid because \(B\) is untouched within the \(n\) steps in the middle.

    So throwing away all \(\emptyword\)-productions and unit productions from \(\hat{P}\) gives us a new set of productions \(\mathring{P}\) with the same language, except for the empty word.
\end{proof}

We are one step closer to the CNF, but we are not quite there yet.

\begin{lemma}[Production Rule without mixing Terminals and Non-Terminals]
    \label{lem:remove-mix}%
    For a CFG \(G = \pqty{N, \Sigma, P, S}\) without \(\emptyword\)-productions, we have a CFG \(G' = \pqty{N', \Sigma, P\, S}\) with the same accepted language \(\langacc\pqty{G'} = \langacc\pqty{G}\), and such that every production is of the form \(A \prodrule a\), \(A \prodrule B_1 \cdots B_k\)for \(k \geq 1\), where \(A, B_1, \ldots, B_k \in N'\) and \(a \in \Sigma\).
\end{lemma}

\begin{proof}
    For each \(a \in \Sigma\), we add a new non-terminal \(A_a\) to \(N\) to get \(N'\). We add a production rule that reads \(A_a \prodrule a\) for each \(a \in \Sigma\). Finally, we replace any \(a \in \Sigma\) on the right-hand side of any production rule originally in \(P\) with \(A_a\). This gives us our new set of productions \(P'\).

    For \(\langacc\pqty{G} \subseteq \langacc\pqty{G'}\), if in \(G\) we have \(A \prodrule \cdot\) consisting of many terminals \(a_1, a_2, \ldots\). Then this is replaced with \(A,{a_1}, A_{a_2}, \ldots\), then applying \(A_{a_1} \prodrule a_1\), \(A_{a_2} \prodrule a_2\), etc. gives us the same terminal string.

    On the other hand, note the new non-terminals only appear on the right-hand side of the production rules, apart from those of the form \(A_{a} \prodrule a\) where are replaced.

    So \(G\) and \(G'\) indeed accepts the same language.
\end{proof}

The final step is now bringing down the number of non-terminals on the right-hand side of each production rule to at most 2.

\begin{theorem}[Chomsky Normal Form]
    \label{thm:chomsky-normal-form}%
    Any CFG \(G = \pqty{N, \Sigma, P, S}\) gives rise to a CFG \(\bar{G} \) in CNF with \(\langacc\pqty{G'} = \langacc\pqty{G} \setminus \set{\emptyword}\).
\end{theorem}

\begin{proof}
    From \(G = \pqty{N, \Sigma, P, S}\), we form the \(\mathring{G}\) without \(\emptyword\)-productions or unit productions by \autoref{thm:remove-empty-unit}, and then \(G'\) by \autoref{lem:remove-mix}. The latter does not add \(\emptyword\)-productions or unit productions, so everything in \(\mathring{P}'\) is of the form \(A \prodrule a\) or \(A \prodrule B_1 \cdots B_k\) for \(k \geq 2\).

    Now, for each production rule \(A \prodrule B_1 \cdots B_k\) with \(k \geq 3\), we introduce a new non-terminal \(C\) and replace it with \(A \prodrule B_1 C\) and \(C \prodrule B_2 \cdots B_k\). The language is unchanged (new non-terminals only appear on the left-hand side in one production rule). We keep applying this until all right-hand sides have at most 2 non-terminals, and we have our desired \(\bar{G}\).
\end{proof}

Given an arbitrary CFG \(G = \pqty{N, \Sigma, P, S}\) and \(w \in \Sigma\kstar\), do we have an algorithm to decide whether \(w \in \langacc\pqty{G}\)? If \(G\) is CNF, then it is definitely of type 1 (non-contracting), though we should not do this in practice as it is inefficient, since we have blown up the number of production rules.

What about \(\emptyword \in \langacc\pqty{G}\)? When we enlarge \(P\) to \(\hat{P}\) in \autoref{thm:remove-empty-unit}, we note \(\emptyword \in \langacc\pqty{\hat{G}} = \langacc\pqty{G}\) if and only if \(S \prodrule \emptyword\) is in \(\hat{P}\).

What about a CNF for \(G\) but with \(\emptyword \in \langacc\pqty{G}\)? We can try to throw in again the \(\emptyword\)-production \(S \prodrule \emptyword\) to the CNF, but this \(\emptyword\)-production could be used to obtain other words at a later stage. So instead, say the CNF is \(\pqty{N, \Sigma, P, S}\), we introduce a new start symbol \(T\) to \(N\), and we enlarge \(P\) to \(Q\) by adding \(T \prodrule \emptyword \mid S\). Then we take \(\bar{G} = \pqty{N \cup \set{T}, \Sigma, Q, T}\) as our new CFG.

\begin{example}[Balanced Parentheses Revisited]
    \label{ex:balanced-parentheses-revisited}%
    Given the production rule in \autoref{prop:balanced-parentheses}, we have no unit productions, but we do have \(S \prodrule [S] \mid SS\) which mixes terminals and non-terminals, and also \(S \prodrule \emptyword\).

    By \autoref{thm:remove-empty-unit}, we can add in the rule \(S \prodrule []\) to get the production rule
    \[
        S \prodrule[][] [S] \mid SS \mid [\ ]
    \]

    By \autoref{lem:remove-mix}, we introduce new non-terminals \(L\) and \(R\), with production rules
    \[
        S \prodrule LSR \mid SS \mid LR, \quad L \prodrule[][] [, \quad R \prodrule[][] ].
    \]

    By \autoref{thm:chomsky-normal-form}, we add \(C\) and replace the first production rule with
    \[
        S \prodrule LC \mid SS \mid LR, \quad C \prodrule SR, \quad L \prodrule[][] [, \quad R \prodrule[][] ].
    \]

    This is exactly \autoref{ex:brackets-in-disguise} in disguise!
\end{example}

\begin{remark}
    There is no algorithm that can solve whether two context-free grammars accept the same language. (In the sense that, we have proved no algorithm could exist, not that we have not found one yet.)
\end{remark}

\subsection{Parse Trees and the Pumping Lemma for Context-Free Languages}

We picture how to derive a sentence in a CFG, like a path in the transition diagram of a DFA.

\begin{definition}[Parse Tree]
    Given a CFG \(G\) and a derivation (without \(\emptyword\)-productions) of a word \(w \in \langacc\pqty{G} \setminus \set{\emptyword}\), a \term{parse tree} is a rooted tree, which is a connected finite graph with a base vertex labelled \(S\) with no closed loops, drawn downwards from \(S\) and representing the productions used in deriving the word \(w\). Each vertex \(v\) is labelled with a symbol from \(N \cup \Sigma\) if \(\deg v > 1\), but from \(\sigma\) if \(\deg v = 1\), known as a \term{leaf vertex}. The leaves of the tree, read from left to right, give the word \(w\).

    We construct the tree as follows -- this can be visuallised in \autoref{fig:parse-tree}:
    \begin{enumerate}[label=(\arabic*)]
        \item Label the root with \(S\).
        \item The first production \(S \prodrule \alpha_1\) gives \(\abs{\alpha_1}\) branches down from \(S\), labelled by symbols of \(\alpha_1\), from left to right.
        \item For the next production \(X \prodrule \alpha_2\), add \(\abs{\alpha_2}\) branches from this \(X\) with the labelling.
        \item We continue going until the derivation is finished. Now all the leaves are labelled by terminals.
        \item To help with reading, we extend the terminals down until all of them are at the same bottom level, and then we can read the leaves from left to right to get the word \(w\).
    \end{enumerate}

    We say the root is at level \(0\) and the \term{depth} \(n\) of the tree is the maximum level of any vertex in the tree, so we have \(\pqty{n + 1}\) levels labelled \(0, 1, \ldots, n\).
\end{definition}

\begin{remark}
    If \(G\) is a CFG in CNF form, then a parse tree has \(\leq 2^i\) symbols in level \(i\), as each vertex has at most two decedents.
\end{remark}

\begin{theorem}[Pumping Lemma for Context-Free Languages]
    \label{thm:pumping-lemma-cfl}%
    Let \(L\) be a context-free language. Then there exists some \(n \in \NN\) such that for any \(u \in L\) with \(\abs{u} \geq n\), we can write \(u\) as five subwords \(u = vwxyz\), such that
    \begin{enumerate}[label=(\arabic*)]
        \item \(w\) and \(y\) are not both \(\emptyword\),
        \item \(1 \leq \abs{w x y} \leq n\),
        \item for all \(k \geq 0\), we have \(v w^k x y^k z \in L\).
    \end{enumerate}
\end{theorem}

\begin{proof}
    By \autoref{thm:chomsky-normal-form}, take a CFG \(G\) for \(L\) that is CNF. Take \(n \geq 2^{m + 1}\) for \(m = \abs{N}\) which is the number of non-terminal symbols in \(G\).

    If \(u \in L\) and \(\abs{u} \geq n\), then any parse tree for \(u\) has depth at least \(m + 1\), otherwise there are not enough symbols.

    Let \(\Pi\) be a path from the root down to the last level of the parse tree, passing only through non-terminals, except for the very final vertex, for example by working back from the last production. Then the path passes through at least \(m + 1\) non-terminals, and so by the pigeonhole principle, some non-terminal \(A\) occurs twice along \(\Pi\). Let \(A\) be the first repeated non-terminal going from the bottom.

    If we use the lower \(A\) vertex as a root for the subtree below it, and regard it as a smaller parse tree with start symbol \(A\), we will obtain some word \(x\). If we do the same with the upper \(A\), we will obtain some word \(w x y\). This is illustrated in \autoref{fig:parse-tree-pumping-lemma}.

    Note that the vertex \(A\) has at least one downward branch not leading to the lower \(A\), but ending in terminals, since the grammar is in Chomsky normal form. Hence, the words \(w\) and \(y\) cannot both be empty.

    Note that the upper subtree has depth at most \(m + 1\), as we took the closest repeat from the bottom, and hence \(\abs{w x y} \leq 2^{m + 1} = n\).

    For pumping up, we can replace the lower tree by a copy of the upper tree, and extend the terminals down, to obtain a parse tree for a new word, i.e., replacing the \(x\) with \(w x y\), and we may repeat this process many times (as we still have a copy of the lower tree), as in \autoref{fig:parse-tree-pumping-up}.

    For pumping down, we may replace the upper tree by the lower tree (but we may only do this once) to get \(v x z\), as in \autoref{fig:parse-tree-pumping-down}.
\end{proof}

\begin{remark}
    Context-free languages are not invariant under intersections or complement.
\end{remark}

\begin{example}
    \begin{itemize}
        \item The language
        \[
            L = \set{a^i b^i c^i}{i \in \NN}
        \]
        is not context-free. Suppose if it were context-free, whenever we write \(\alpha = a^n b^n c^n\) as \(vwxyz\) with \(\abs{wxy} \leq n\), and \(w, y\) not both empty. Then \(w x y\) cannot contain both \(a\)s and \(c\)s. Say there are no \(a\)s without loss of generality.

        Take a suitable \(n\) from \autoref{thm:pumping-lemma-cfl}, then
        \[
            v w^k x y^k z \in L
        \]
        for \(k \geq 2\). Now this has the same number of \(a\)s, but certainly more \(b\)s and/or more \(c\)s. This gives a contradiction, hence this is not a context-free language.

        \item Consider \(\Sigma = \set{a, b, c, d}\) and \(L = \set{w \in \Sigma\kstar}{w \text{ has the same number of \(a\)s, \(c\)s and same number of \(b\)s, \(d\)s}}\). Then \(L\) is not context-free. Suppose \(n\) is the pumping number, and let
        \[
            j = a^n b^n c^n d^n \in L.
        \]

        So \(u = vwxyz\) where \(\abs{wxy} \leq n\) and \(w, y\) not both empty, and hence \(wxz \in L\). So the number of \(a\)s and \(c\)s is the same, and the number of \(b\)s and \(d\)s is the same. But \(wxy\) cannot contain both \(a\)s and \(c\)s, or both \(b\)s and \(d\)s, so pumping down gives a contradiction.

        Now, if \(c = A\) and \(d = B\) for group \(\ZZ \times \ZZ\), with \(a = \pqty{1, 0}, b = \pqty{0, 1}\). Then \(L\) is all words representing the identity, but is not context-free. But if we look at \(\ZZ\) with \(a = 1\) and \(A = -1\), this is context-free, although not regular.

        \item Suppose \(G = \angBrac{a, b}\) with \(A = a\inverse\) and \(B = b\inverse\), and set \(\Sigma = \set{a, b, A, B}\). Consider \(w \in \Sigma\kstar\) as an element \(g\) of \(G\) with \(\emptyword\) as identity.
        
        Whenever we see \(aA\), \(Aa\), \(bB\), \(Bb\) as a subword of \(G\), we may cancel. The group that these are the \emph{only} allowed cancelling relations is the \term{free group} on two generators, \(F_2 = \angBrac{a, b}\) or rank \(2\). In other words, \(F_2\) contains exactly \emph{reduced words} of \(\Sigma\kstar\) with no \(aA\), \(Aa\), \(bB\), \(Bb\) as subwords.

        The word problem of \(F_2 = \angBrac{a, b}\) is a context-free language:
        \[
            S \prodrule \emptyword \mid S ?_1 S ?_2 S
        \]
        where the \(\pqty{?_1, ?_2}\) are paired up as: \(\pqty{a, A}\), \(\pqty{A, a}\), \(\pqty{b, B}\), \(\pqty{B, b}\).
    \end{itemize}
\end{example}

\small

Similar to regular languages, we have a result on group theory and context-free languages.

\begin{theorem}[Virtually Free Groups and Context-Free Languages]
    A finitely-generated group has context-free language (with respect to any finitely generated set), if and only if the group has a finite index subgroup which is free (i.e., \term{virtually free}).
\end{theorem}
